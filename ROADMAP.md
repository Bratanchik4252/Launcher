# ROADMAP лаунчера NOVACRAFT

> Лаунчер Minecraft **1.7.10** (версия проекта сменилась с 1.12.2!). Electron + React + TypeScript.
> Код лежит в отдельном репозитории `C:\Users\danie\NovaCraft-Launcher` (GitHub: Bratanchik4252/Launcher).
> Этот файл — план и список TODO. Сайт-ROADMAP — в корне `ROADMAP.md` сайта.

**Жёсткие требования (от владельца):**
- Без бэкдоров и дыр, нельзя заддосить, нельзя украсть токены.
- **IP игрового сервера не палится**: не лежит в клиенте/exe, выдаётся из БД, серверный мод проверяет токен.
- Нельзя зайти на сервер с левыми клиентскими модами (серверный мод проверяет мод-лист + токен лаунчера).
- Стиль — как у сайта NOVACRAFT (тёмный glass, зелёные акценты).
- Авторизация — те же аккаунты, что на сайте (Supabase), вход по нику ИЛИ email.
- Сейчас сервер на хостинге (есть защита), позже — свой ПК: тогда поднимать прокси + фаервол.

## Что НЕ переносим из старого кода (найдено при ревизии)

| Проблема | Статус |
|---|---|
| `devAuthBypass` — вход без пароля | удалить |
| Offline-запуск без accessToken/uuid | убрать (ник из аккаунта, автосервер) |
| Модпак без checksum → RCE при подмене | добавить SHA-256 |
| Edge Functions с `SUPABASE_SERVICE_ROLE_KEY` публично | не использовать; JWT + anon |
| `api-auth` с CORS `*`, HTTP, без rate limit | удалить |
| `mock-api` с паролями открытым текстом | удалить |
| PowerShell `Expand-Archive` инъекция | заменить на нативный unzip |
| Токены в plaintext при недоступном safeStorage | не хранить |
| IP сервера в `launcher.config.json` | убрать, адрес из БД |
| Токен ничем не проверяется | проверка через серверный мод + Edge Function |
